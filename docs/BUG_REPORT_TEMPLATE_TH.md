## 🚨 4. การวิเคราะห์ระดับความรุนแรง (Severity Matrix)
โปรดประเมินและทำเครื่องหมายเลือกความรุนแรงของปัญหานี้:
* [ ] 🔴 **High (วิกฤต)**: ข้อบกพร่องร้ายแรงที่ทำให้ผู้ใช้งานไม่สามารถทำแบบทดสอบหรือทำงานต่อจนจบได้ (เช่น หน้าแรกค้าง, กดส่งคำตอบไม่ได้, ล็อคอินไม่ผ่าน)
* [ ] 🟡 **Medium (ปานกลาง)**: ระบบสามารถทำงานจนจบขั้นตอนได้ แต่ข้อมูลหรือพฤติกรรมมีความเบี่ยงเบนผิดพลาด (เช่น คะแนนคำนวณผิด, สถิติไม่แสดง, ประวัติตกหล่น)
* [ ] 🟢 **Low (ต่ำ)**: ข้อบกพร่องเรื่องการแสดงผลที่ไม่มีผลเสียต่อการประมวลผล (เช่น ตัวอักษรเอียง, สีปุ่มไม่ตรง, สะกดคำภาษาไทยผิด)
