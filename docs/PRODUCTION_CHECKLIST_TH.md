# รายการตรวจสอบเพื่อเปิดบริการจริง (Production Verification Checklist)

รายการประเมินความพร้อมและเสถียรภาพของระบบก่อนให้ผู้ใช้งานจริงเข้าใช้งานแบบทดสอบ Moonlight Exam

---

## 📋 1. ระบบยืนยันตัวตนและความปลอดภัย (Authentication & Auth Check)
- [ ] แอดมินสามารถลงชื่อเข้าใช้งานได้ปกติ (และเข้าสู่หน้าจอจัดการแอดมินได้)
- [ ] สามารถสมัครสมาชิกบัญชีผู้ใช้ใหม่ได้สมบูรณ์ผ่านหน้าบ้าน
- [ ] ผู้สมัครสมาชิกใหม่จะอยู่ในสถานะ **pending** ทันที และไม่สามารถล็อกอินเข้าสู่หน้าแรกหรือเปิดดูข้อสอบได้
- [ ] หน้าจออนุมัติของ Admin ตรวจสอบผู้ใช้ใหม่และสามารถกด **Approve (อนุมัติ)** ได้ปกติ
- [ ] ผู้ใช้งานที่ได้รับการ Approve สามารถล็อกอินผ่านอีเมลตัวเต็มและรหัสผ่านได้สำเร็จ
- [ ] ผู้ใช้ที่ถูกกด **Reject (ปฏิเสธสิทธิ์)** จะถูกขัดขวางไม่ให้ทำกิจกรรมใดๆ ในระบบ
- [ ] ไม่พบช่องโหว่ความลับ รหัสผ่าน คีย์ หรือ Secret Key หลุดรั่วไปกับโค้ดโครงการบน Git

---

## 📋 2. ระบบการทำแบบทดสอบ (Quiz & Exam Pack Check)
- [ ] สามารถดึงคำถามวิชาทั่วไปแบบสุ่มได้รวดเร็ว (มีค่าเป็น `"generatedFromPack": true` ในส่วนตอบรับของ API เสมอ)
- [ ] สามารถเริ่มทำแบบทดสอบชุดวิชา (Exam Set) ได้ถูกต้องและคำถามแสดงผลตรงตามเงื่อนไขหมวด
- [ ] บันทึกและส่งกระดาษคำตอบเสร็จสิ้น ข้อมูลประวัติการสอบถูกเขียนและคำนวณคะแนนอย่างถูกต้อง
- [ ] ค่าสถิติในหน้าข้อมูลของฉัน (Stats) ได้รับการประมวลผลเพิ่มขึ้นทันทีผ่านเอกสาร `userStatsSummary`
- [ ] ตารางแสดงประวัติสอบย้อนหลัง (History) แบ่งแสดงผลอย่างรวดเร็ว (Pagination)

---

## 📋 3. ระบบความเสถียรและการควบคุมค่าใช้จ่าย (Server Stability & Budgets)
- [ ] แอดมินล็อกอินดูรายการผู้เรียนได้ปกติและข้อมูลแบ่งแสดงหน้าได้อย่างเสถียร (Admin Pagination Working)
- [ ] ตัวกรองความปลอดภัย App Check อยู่ในโหมดสังเกตการณ์ (`APP_CHECK_ENFORCE=false`) เพื่อป้องกันผู้ใช้โดนล็อก
- [ ] ตั้งค่าการแจ้งเตือนยอดบิลเกณฑ์งบประมาณบน Google Cloud Billing สำเร็จที่ $10/เดือน
- [ ] รันการตรวจสอบสถานะเซิร์ฟเวอร์หลักผ่าน API Health check ตอบกลับเป็นสถานะ `{"status":"ok"}`
- [ ] หน้าเว็บบราวเซอร์แจ้งเตือนและระบุข้อความแนะนำภาษาไทยอย่างชัดเจนเมื่อถูก Rate Limit (Error 429) โดยไม่ทำลายข้อมูลหรือบังคับออกจากระบบ
- [ ] ยืนยันการรันระบบบน Revision ล่าสุดของ Cloud Run
