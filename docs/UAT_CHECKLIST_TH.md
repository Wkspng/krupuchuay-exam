# UAT Checklist (รายการตรวจสอบการทดสอบโดยผู้ใช้) - Moonlight Exam

เอกสารนี้ใช้สำหรับนำทางผู้ทดสอบ (Beta Testers) และทีมพัฒนาระบบเพื่อตรวจสอบความสมบูรณ์ ความถูกต้อง และประสิทธิภาพของระบบสอบ Moonlight Exam ก่อนขึ้นระบบจริง (Production Launch)

---

## 👥 1. บัญชีสำหรับใช้ทดสอบ (Test Accounts)

สำหรับการทดสอบระบบในขั้นตอน UAT นี้ ให้ใช้บัญชีทดสอบที่กำหนดไว้ดังนี้:
* **Admin Account (ผู้ดูแลระบบ)**: `admin_tester` (ใช้สำหรับอนุมัติสมาชิกและจัดการระบบ Exam Pack)
* **Approved User Accounts (ผู้ใช้ที่ได้รับอนุมัติ)**: 
  * `user_tester01` (ผู้ทดสอบวิชาภาค ก.)
  * `user_tester02` (ผู้ทดสอบวิชาทั่วไป)
  * `user_tester03` (ผู้ทดสอบวิชาชีพครู)
* **Pending User Account (ผู้ใช้รออนุมัติ)**: `pending_tester` (ใช้จำลองการสมัครและเข้าหน้ารออนุมัติ)

> [!WARNING]
> ห้ามบันทึกรหัสผ่านจริง (Plain-text Password) ลงในเอกสารฉบับนี้ หรือคอมมิตลง GitHub โดยเด็ดขาด ให้ใช้รหัสผ่านชั่วคราวที่มีความปลอดภัยสูงและแจ้งผู้ทดสอบเป็นการภายใน

## 🌐 3. เกณฑ์การตรวจสอบประสิทธิภาพทางเทคนิค (Non-Functional Requirements)

### 3.1 ความถูกต้องของ API (Network Inspection)
* [ ] **`/api/categories`**: ตอบรับด้วยสถานะ `200 OK` และมีฟิลด์ `totalQuestions` แนบมาด้วยทุกหมวดหมู่
* [ ] **`/api/questions/random`**: ตอบรับด้วยสถานะ `200 OK` และมีตัวแปร `"generatedFromPack": true` ยืนยันว่าดึงข้อมูลจาก Exam Pack จริง
* [ ] **Error Rate**: ไม่มีข้อผิดพลาดระดับ `500 Internal Server Error` หรือ `429 Too Many Requests` จากการใช้งานปกติ

### 3.2 ความสวยงามและการจัดรูปหน้า (UI Layout)
* [ ] **Mobile Responsive**: หน้าเว็บแสดงผลได้ดีบนหน้าจอสมาร์ทโฟน (iOS และ Android) ตัวหนังสือไม่ล้น ปุ่มกดง่าย
* [ ] **Desktop Layout**: การ์ดแสดงผลเรียงตัวเป็นระเบียบสวยงาม ระยะห่างช่องว่างและโทนสีถูกต้อง
* [ ] **Loader & Error States**: มีหน้าจอแสดงผลเวลาโหลด (Loader) หรือแสดงกล่องข้อความเตือนและปุ่ม "ลองใหม่" (Retry UI) ที่ผู้ใช้ทั่วไปเข้าใจได้ง่ายเมื่อเครือข่ายมีปัญหา

## 🚨 4. วิธีการรายงานปัญหา (How to Report Errors)

หากผู้ทดสอบ UAT พบปัญหาขัดข้องใดๆ ขอความกรุณารายงานข้อมูลโดยระบุ:
1. **หน้าจอที่เกิดปัญหา** (เช่น หน้าแรก, หน้าทำข้อสอบ, หน้าประวัติ)
2. **ขั้นตอนที่ทำก่อนเกิดปัญหา** (Step-by-step instructions)
3. **อุปกรณ์และเว็บเบราว์เซอร์ที่ใช้งาน** (เช่น iPhone 15 Chrome, PC Safari)
4. **ภาพบันทึกหน้าจอ** (Screenshot/Video)
5. **ระดับความรุนแรง (Severity)**:
   - 🔴 **High**: ระบบขัดข้องจนไม่สามารถทำข้อสอบต่อหรือส่งคะแนนได้
   - 🟡 **Medium**: ทำงานได้สำเร็จแต่มีจุดผิดเพี้ยนด้านข้อมูลหรือการคำนวณประวัติ
   - 🟢 **Low**: แสดงผลผิดพลาดทางสายตา (Visual Bugs) หรือคำสะกดผิด
