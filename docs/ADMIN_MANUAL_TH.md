# คู่มือผู้ดูแลระบบ (Admin Operation Manual)

คู่มือนี้แนะนำการใช้งานระบบหลังบ้าน Moonlight Exam ในการอนุมัติผู้ใช้งาน และการตั้งค่าพื้นฐานสำหรับผู้ดูแลระบบ

---

## 1. วิธีเข้าใช้งานระบบ
1. เปิดเว็บบราวเซอร์แล้วไปที่: [https://moonlight-krupuchuay-exam.web.app](https://moonlight-krupuchuay-exam.web.app)
2. ระบบจะแสดงหน้าจอเข้าสู่ระบบ (Login)

---

## 2. วิธีลงชื่อเข้าใช้งานสำหรับ Admin
1. กรอก **อีเมลเต็ม** ของแอดมินในช่องอีเมล เช่น `admin@example.com`
   > [!IMPORTANT]
   > ต้องกรอกอีเมลเต็มรูปแบบที่มีเครื่องหมาย `@` และโดเมนเนมเท่านั้น ไม่สามารถกรอกเฉพาะชื่อผู้ใช้สั้นๆ หรือ username
2. กรอกรหัสผ่านในช่อง Password
3. คลิกปุ่ม **เข้าสู่ระบบ**

---

## 3. วิธีการตรวจสอบผู้ใช้งานและการอนุมัติ
หลังจากเข้าสู่ระบบด้วยบัญชีแอดมินแล้ว แถบ **"จัดการผู้ใช้งาน"** (Admin) จะปรากฏขึ้นด้านบน

### การตรวจสอบสถานะผู้สมัคร
- **ผู้สมัครรออนุมัติ (Pending Users)**: แสดงรายการผู้ใช้ใหม่ที่ลงทะเบียนเข้ามาและกำลังรอให้อนุมัติเพื่อใช้งานระบบ
- **ผู้ใช้ที่อนุมัติแล้ว (Approved Users)**: ผู้ใช้ที่ได้รับสิทธิ์ให้ทำข้อสอบได้ตามปกติ
- **ผู้ใช้ที่ปฏิเสธสิทธิ์ (Rejected Users)**: ผู้ใช้ที่โดนระงับสิทธิ์หรือยกเลิกบัญชี

### วิธีอนุมัติผู้ใช้ (Approve User)
1. ไปที่แท็บ **"จัดการผู้ใช้งาน"**
2. มองหาผู้ใช้ในหมวด **Pending**
3. คลิกปุ่ม **"อนุมัติ (Approve)"**
4. สถานะผู้ใช้จะเปลี่ยนเป็น **approved** ทันที และสามารถลงชื่อเข้าใช้งานระบบเพื่อทำข้อสอบได้

### วิธีปฏิเสธ/ระงับสิทธิ์ผู้ใช้ (Reject User)
1. ไปที่หมวดผู้ใช้ที่ต้องการระงับสิทธิ์
2. คลิกปุ่ม **"ปฏิเสธ (Reject)"**
3. บัญชีดังกล่าวจะเปลี่ยนสถานะเป็น **rejected** และถูกสกัดกั้นไม่ให้เข้าสู่หน้าแรกหรือส่งกระดาษคำตอบได้

---

## 4. วิธีออกจากระบบ (Logout)
1. คลิกที่รูปโปรไฟล์หรือสัญลักษณ์ผู้ใช้ที่มุมขวาบน
2. คลิกปุ่ม **ออกจากระบบ (Logout)**

---

## 5. การแก้ไขปัญหาเข้าสู่ระบบเบื้องต้น

### ⚠️ ปัญหา: กรอกอีเมลสั้นๆ แล้วขึ้นแจ้งเตือนรูปแบบผิดพลาด
- **สาเหตุ**: กรอกชื่อสั้น (เช่น `test11`) ในช่องล็อกอิน
- **การแก้ไข**: ระบบถูกจำกัดให้อ่านเฉพาะอีเมลเต็มตัว (เช่น `test11@gmail.com`) กรุณาแจ้งให้ผู้ใช้กรอกอีเมลให้ครบรูปแบบ

### 🔒 วิธีการรีเซ็ตรหัสผ่าน (Reset Password) ผ่าน Firebase Console
หากแอดมินหรือผู้ใช้ลืมรหัสผ่าน ให้ใช้วิธีรีเซ็ตแบบปลอดภัยผ่านคอนโซลดังนี้:
1. เข้าไปที่ [Firebase Console](https://console.firebase.google.com/) เลือกโครงการ **moonlight-krupuchuay-exam**
2. ไปที่เมนู **Build** > **Authentication** > **Users**
3. ค้นหาอีเมลของผู้ใช้ที่ต้องการรีเซ็ต
4. คลิกสัญลักษณ์จุดสามจุดด้านขวามือของแถวรายชื่อผู้ใช้
5. เลือก **Reset password** ระบบจะส่งอีเมลลิงก์เปลี่ยนรหัสผ่านที่ปลอดภัยไปให้ผู้ใช้งานโดยตรง

> [!WARNING]
> **ข้อควรระวังเรื่องรหัสผ่าน Admin**:
> - ห้ามนำรหัสผ่านแอดมินไปใช้ร่วมกับแพลตฟอร์มอื่น
> - หลีกเลี่ยงการเปิดเผยหน้าจอ Firebase Console ขณะปฏิบัติงาน
> - หากต้องเปลี่ยนรหัสผ่านแอดมิน ให้ทำผ่านระบบ Firebase Authentication โดยตรง ห้ามบันทึกรหัสผ่านลงในไฟล์หรือโค้ดโปรเจกต์
