# คู่มือจัดการข้อสอบ (Question Management Guide)

คู่มือนี้สำหรับแอดมินในการเพิ่ม แก้ไข ลบ และนำเข้าข้อสอบผ่านระบบจัดเก็บและอัปเดตข้อมูลข้อสอบอย่างมีประสิทธิภาพ

---

## 1. โครงสร้างหมวดข้อสอบ
ข้อสอบแต่ละข้อต้องผูกเข้ากับหมวดวิชา (`categories`) เสมอ ตัวอย่างหมวดวิชาที่มีในระบบ:
- ความสามารถทั่วไป
- ภาษาไทย
- รัฐธรรมนูญและกฎหมายการศึกษา
- วิชาชีพครู
- สังคม เศรษฐกิจ การเมือง บ้านเมือง

---

## 2. โครงสร้างฟิลด์ข้อมูลข้อสอบที่ถูกต้อง
ข้อสอบแต่ละข้อที่ถูกสร้างหรือนำเข้า ต้องมีโครงสร้างข้อมูลดังนี้:

| ชื่อฟิลด์ | คำอธิบาย | เงื่อนไขความถูกต้อง |
| :--- | :--- | :--- |
| **questionText** | โจทย์คำถาม | ห้ามเป็นค่าว่าง |
| **choices** | ตัวเลือกคำตอบ 4 ตัวเลือก | ต้องเป็นอาร์เรย์ข้อความความยาว 4 เท่านั้น ห้ามมีตัวเลือกว่าง |
| **correctAnswerIndex** | ดัชนีตัวเลือกคำตอบที่ถูกต้อง | ต้องเป็นตัวเลขจำนวนเต็มตั้งแต่ **0 ถึง 3** (0 = ก, 1 = ข, 2 = ค, 3 = ง) |
| **explanation** | อธิบายเฉลย | แสดงผลหลังผู้ทำข้อสอบกดส่งข้อสอบ |
| **categoryId** | รหัสไอดีหมวดวิชา | ต้องเป็นไอดีที่มีอยู่จริงในระบบ |
| **categoryName** | ชื่อหมวดวิชา | สอดคล้องกับไอดีหมวดวิชา |
| **difficulty** | ระดับความยาก | ต้องมีค่าเป็น `easy`, `medium`, หรือ `hard` (ค่าเริ่มต้น: `medium`) |

---

## 3. วิธีจัดการข้อสอบ

### การเพิ่มข้อสอบทีละข้อ
1. เข้าเมนู **"คลังข้อสอบ" (Question Bank)**
2. คลิกปุ่ม **"เพิ่มข้อสอบใหม่"**
3. กรอกคำถาม ตัวเลือก คำอธิบาย ระบุหมวดวิชา และระดับความยากให้ครบถ้วน
4. คลิกปุ่ม **"บันทึก"**

### การแก้ไขข้อสอบ
1. ค้นหาข้อสอบที่ต้องการแก้ไขจากรายการคลังข้อสอบ
2. คลิกปุ่ม **"แก้ไข"** ในแถวข้อสอบนั้นๆ
3. ปรับปรุงข้อมูลตามต้องการแล้วกด **"บันทึก"**

### วิธีปิดใช้งานข้อสอบ (แทนการลบถาวร)
> [!IMPORTANT]
> **ห้ามลบข้อสอบออกจากระบบอย่างถาวร** เนื่องจากอาจมีผลกระทบย้อนหลังต่อประวัติการสอบ (History/Attempts) ของผู้เรียนที่เคยทำข้อสอบข้อนี้ไปแล้ว
- ให้ใช้วิธีเปลี่ยนสถานะข้อสอบเป็น **ปิดใช้งาน** หรือตั้งค่า `isActive = false` ในหน้าแก้ไขข้อสอบแทน

---

## 4. วิธีนำเข้าข้อสอบปริมาณมาก (Bulk Import Questions)
ระบบรองรับการนำเข้าข้อสอบรูปแบบไฟล์ JSON (จำกัดไม่เกิน 500 ข้อต่อครั้ง) ผ่านหน้าเว็บของแอดมิน:
1. เตรียมไฟล์ JSON ที่มีรูปแบบอาร์เรย์ดังนี้:
   ```json
   [
     {
       "categoryName": "ภาษาไทย",
       "questionText": "คำถามตัวอย่าง?",
       "choices": ["ตัวเลือก 1", "ตัวเลือก 2", "ตัวเลือก 3", "ตัวเลือก 4"],
       "correctAnswerIndex": 1,
       "explanation": "คำอธิบายตัวอย่าง...",
       "difficulty": "medium",
       "isActive": true
     }
   ]
   ```
2. ในหน้าคลังข้อสอบ กดปุ่ม **"นำเข้าไฟล์ข้อสอบ (Import)"**
3. เลือกไฟล์ข้อสอบที่เตรียมไว้และกดสมัครนำเข้าข้อมูล

---

## ⚠️ ข้อควรระวังหลังการแก้ไขข้อสอบ (Stale Pack Notification)
เมื่อแอดมินเพิ่ม แก้ไข ปิดใช้งาน หรือนำเข้าข้อสอบสำเร็จแล้ว:
- หมวดวิชานั้นจะถูกตั้งสถานะเป็น **Stale (ข้อมูลไม่อัปเดต)** ทันที
- **ต้องรันคำสั่งคอมไพล์ Exam Pack เสมอ** เพื่ออัปเดตชุดข้อสอบในระบบคลาวด์ให้เป็นเวอร์ชันล่าสุดและแสดงผลไปหาผู้ใช้งานจริง (ดูรายละเอียดการรันในคู่มือการใช้งาน Exam Pack)
